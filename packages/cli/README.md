# @remixapp/cli

Build, develop, and deploy remixApp project packages.

```sh
remix-cli dev
remix-cli build
remix-cli deploy
```

`remix-cli build` validates `remix.config.ts` and creates a `.remixprj` package containing a normalized `project.json`.

See the repository [README](https://github.com/beyondspace-dev/remix-app#readme) and [Korean README](https://github.com/beyondspace-dev/remix-app/blob/main/README_ko.md) for the full project workflow.
